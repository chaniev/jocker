# PROD-002 Защита скрытых карт в истории и экспорте

- Статус: Backlog
- Приоритет: P0
- Этап: Сначала
- Тип: Проверка и исправление дефекта
- Предварительный объём: Небольшой–средний
- Создано: 2026-11-15
- Источник предложения: [продуктовый бэклог](README.md)

## Проблема

По коду история текущей раздачи выдаётся без проверки завершения, а экран истории формирует стартовые руки всех участников. Риск раскрытия скрытой информации подтверждён статически; воспроизведение на устройстве ещё требуется.

## Ожидаемый результат

До завершения раздачи игрок не может увидеть чужие закрытые карты через историю, экспорт или иной путь из интерфейса.

## Объём задачи

- Воспроизвести путь: начать раздачу с несколькими картами → сделать заказ → открыть «Очки» → выбрать текущую раздачу → проверить руки и экспорт.
- Разрешать подробную историю с полными руками и её экспорт только для завершённых раздач; оставить текущий счёт доступным.
- Защитить все точки входа в подробности и выдачу данных для экспорта, включая восстановленную партию.

## Критерии приёмки

- [ ] В незавершённой раздаче чужие стартовые руки недоступны из таблицы, истории и экспортируемого файла.
- [ ] Для завершённой раздачи по-прежнему доступны полные подробности и экспорт.
- [ ] При попытке открыть недоступные подробности игрок получает понятное объяснение; счёт и уже завершённые раздачи доступны.
- [ ] Проверены три участника, четыре каждый за себя, пары и переходы между раздачами; добавлена целевая регрессионная проверка раскрытия карт.

## Сигнал результата

Ноль воспроизводимых способов раскрыть чужие закрытые карты через перечисленные сценарии.

## Зависимости и связи
