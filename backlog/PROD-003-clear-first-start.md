# PROD-003 Понятный первый запуск и выбор сложности

- Статус: Backlog
- Приоритет: P1
- Этап: Ближайший выпуск
- Тип: Пользовательский сценарий
- Предварительный объём: Средний
- Создано: 2026-11-15
- Источник предложения: [продуктовый бэклог](README.md)

## Проблема

Надписи «3 игрока» и «4 игрока» не объясняют, что остальные места занимают боты. Высокая сложность установлена по умолчанию; названия уровней шуточные. Отдельного знакомства с вариантом правил во входном сценарии не найдено.

## Ожидаемый результат

Знакомый с джокером человек самостоятельно понимает состав стола, выбирает подходящую сложность и начинает игру по правилам приложения.

## Объём задачи

- Явно показать «Вы против ботов», число участников и доступные режимы.
- Дать понятные основные названия и краткие описания трём уровням сложности; шуточные названия при необходимости оставить дополнительными.
- Добавить короткую доступную справку по заказу, козырю, джокеру, премиям и отображению очков.
- Позволить пропустить знакомство и вернуться к справке; сохранять пользовательский выбор.

## Критерии приёмки

- [ ] До начала партии игрок видит, кто управляет местами за столом; для пар обозначен состав команд.
- [ ] Уровни различимы без знания внутренних шуток; сохранённые настройки существующего пользователя не сбрасываются.
- [ ] Справка соответствует текущим правилам и единицам счёта; опытный игрок может начать без обязательного длинного обучения.
- [ ] В наблюдении участник самостоятельно доходит до первых трёх завершённых раздач; затруднения фиксируются по протоколу PROD-014.

## Сигнал результата

Доля самостоятельного прохождения первых трёх раздач; время до первого заказа; понимание состава стола и результата.

## Зависимости и связи

Обозначение партнёра во время игры развивается в [PROD-011](PROD-011-pairs-partner-visibility.md). Наблюдение результата — [PROD-014](PROD-014-player-pilot.md).

## Уточнения перед планированием

- Какую сложность предлагать новым игрокам по умолчанию и нужно ли спрашивать об опыте? Текущее hard не считать согласованным целевым значением.
- Какие отличия локальных правил обязательны в первой короткой справке? Полное обучение с нуля не входит в первую версию.
